# マクロ・ストトン・Include

## ストトン表記

ストトンは、日本語の音名や命令を通常 MML へ置き換える前処理層です。

```mml
テンポ120 音階5 音符4 音量100
ドレミファソラシ↑ド
```

これは概ね次と同じです。

```mml
Tempo=120 o5 l4 v100
cdefgab>c
```

長い語を先に照合するため、`方向左前` が `方向左` と `前` に分割されることはありません。
文字列内の日本語は置換しません。組み込みの全対応語は [従来版の全コマンド表](12-legacy-command-table.md) の「ストトン表記」を参照してください。

## 全角記号

代表的な正規化は次のとおりです。

| 入力 | 変換後 |
|---|---|
| `ｃｄｅ`, `１２３` | `cde`, `123` |
| 全角空白 | 半角空白 |
| `【】` | `[]` |
| `『』` | `{}` |
| `↑`, `↓` | `>`, `<` |
| `♯`, `♭` | `#`, `-` |
| `一`〜`九`, `零`, `〇` | `1`〜`9`, `0` |

## 利用者定義ストトンマクロ

```mml
~{上昇}={cdefg}
上昇 上昇
```

書式は `~{名前}={置換後MML}` です。定義自体は音を出しません。同名の利用者定義は組み込み表より優先されます。
定義はコンパイル全体で保持され、Include ファイルで定義した語も呼び出し元から利用できます。

## 文字列 MML マクロ

`Str` 変数および `#name` は、保持した文字列をコマンド位置で MML として再解釈できます。

```mml
Str Intro={"o5 cdef"}
Intro

#Ending={"gab>c"}
#Ending
```

これは単なる文字列置換ではありません。呼び出した位置の現在トラック状態を使って、内容を再度前処理・解釈します。

## リズムマクロ

`$char{mml}` は半角 1 文字へ MML を割り当て、`Rythm{...}` の中で展開します。

```mml
$b{n36,}
$s{n38,}
Rythm{b s b s}
```

リズムマクロ名は ASCII でなければなりません。リズムブロック内の通常 MML はそのまま残ります。

## Include

```mml
Include(chord2.h)
Include{"chord2.h"}
```

Include の探索や取得はコンパイラコアの責務ではありません。呼び出し側が `IncludeResolver` を提供します。
取得したバイト列は UTF-8/CP932 自動判定後、通常の MML として前処理・実行されます。

CLI は概ね次の順で候補を探します。

1. 入力 MML と同じディレクトリおよびその祖先
2. カレントディレクトリおよびその祖先
3. 各候補の `Include/` サブディレクトリ
4. 実行ファイルと同じディレクトリ

ブラウザ WASM ではファイルシステムを仮定せず、JavaScript 側から名前とバイト列を登録します。

## 標準定義 `stdmsg.h`

コンパイル前に `stdmsg.h` を自動的に読み込みます。GM 音色名やリセット関連の定義はここから供給されます。
見つからない場合は警告になりますが、曲本体のコンパイルは継続します。
曲中で明示した Include が見つからない場合はエラーです。
