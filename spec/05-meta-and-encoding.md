# メタイベントと文字コード

## 対応するテキストイベント

| コマンド | SMF meta type | 用途 |
|---|---:|---|
| `MetaText` / `Text` | `FF 01` | 汎用テキスト |
| `Copyright` | `FF 02` | 著作権 |
| `TrackName` | `FF 03` | 曲名・トラック名 |
| `InstrumentName` | `FF 04` | 楽器名 |
| `Lyric` | `FF 05` | 歌詞 |
| `Marker` | `FF 06` | マーカー |
| `CuePoint` | `FF 07` | キューポイント |

```mml
TrackName={"春の曲"}
Copyright={"2026 Example"}
Lyric={"さくら"}
```

値には文字列リテラルまたは `Str` 値を指定できます。イベントは現在トラックの現在時刻に書かれ、
タイムポインタを進めません。

## 入力文字コード

ファイルのバイト列は、次の規則で解釈します。

1. UTF-8 BOM があれば取り除き、UTF-8 とする。
2. strict UTF-8 として妥当なら UTF-8 とする。
3. それ以外は CP932（Windows-31J）として復号する。

ASCII のみの入力は UTF-8 と CP932 のどちらでも同一です。JavaScript などから既に文字列として渡された入力は
UTF-8 の内部文字列として扱い、自動判定を行いません。

## 内部表現

コンパイラ内部は UTF-8 です。字句解析は Unicode の文字単位で進みます。
従来の Shift_JIS リードバイトを前提とした処理を、ソース解析の途中へ持ち込んではいけません。

## SMF のテキスト出力

従来の日本語 MIDI 環境との互換性のため、テキスト系メタイベントの payload は常に CP932 へ符号化します。
SMF 自体には文字コード宣言がないため、これは SakuraMML の互換仕様です。

CP932 に存在しない文字は `?` に置換し、行番号と Unicode コードポイントを含む警告を返します。
コンパイルは継続し、MIDI ファイルは生成します。

```mml
TrackName={"曲🌸"}  // 絵文字は ? になり、警告される
```

## 正規化の境界

全角構文記号は MML 部分では半角へ変換しますが、`{"..."}` 内の文字列は変換しません。
したがって曲名の全角数字や括弧は、そのまま CP932 へ符号化されます。

## 改行

ソースは LF、CRLF のいずれでも読み取れます。行番号は論理行に対して 1 起点です。
従来仕様の `System.MetaTextEOL` は現行 Rust では未実装であり、指定すると警告して無視します。
