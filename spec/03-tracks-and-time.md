# トラック・チャンネル・時間

## トラック

`Track`、`TR`、`NowTrack` は現在の論理トラックを選びます。現行 Rust の初期トラックは 1 です。

```mml
TR=1 o5 cdef
TR=2 o4 ceg
```

トラックはそれぞれ独立したタイムポインタ、チャンネル、オクターブ、音長、ベロシティ、ゲート、
タイミング補正、`.onNote` 列を持ちます。イベントのない論理トラックは SMF の `MTrk` を生成しません。

## MIDI チャンネル

`Channel` または `CH` は 1〜16 で指定し、MIDI ステータスバイトには 0〜15 として格納します。
新しいトラックの既定チャンネルは `clamp(track - 1, 0, 15)` です。

```mml
TR=1 CH=1 @1 c
TR=10 CH=10 @1 n36
```

`@`、CC、ピッチベンド、ノートは、そのイベントを書いた時点のチャンネルを使います。

## タイムベース

`TimeBase=n` は四分音符あたりの tick 数です。既定値は 96、現行 Rust の範囲は 1〜32767 です。
SMF ヘッダの division フィールドへそのまま書かれます。

タイムベースを変更すると、現在の音長が変更前の既定 `l4` と同じトラックは、新しい `l4` に更新されます。
既に作成済みのイベント時刻を伸縮する命令ではないため、通常は曲の先頭で一度だけ指定します。

## 拍子

`TimeSignature=分子,分母` は現在時刻へ拍子メタイベントを出力し、以後の `Time` 計算にも使います。

```mml
TimeSignature=3,4
```

分母は SMF では 2 の指数で保存されます。互換性のため、一般的な 1、2、4、8、16、32 を使用してください。

## タイムポインタ

各トラックの時刻は絶対 tick で保持します。音符・休符・タイ・和音・連符はタイムポインタを進め、
テンポ、音色、CC、メタテキストなどは通常進めません。

`Time(totalTicks)` または `Time(measure:beat:step)` で直接移動できます。

```mml
Time(384)       // 絶対384 tick
Time(2:1:0)     // 第2小節の先頭
Time(4:3:12)    // 第4小節、第3拍、さらに12 tick
```

小節と拍は 1 起点、step は 0 起点です。計算式は次のとおりです。

```text
beatTicks = timebase * 4 / denominator
time = ((measure - 1 + MeasureShift) * numerator
        + (beat - 1)) * beatTicks + step
```

負の結果は 0 へ丸めます。移動後は直前音とのタイを解除します。

## 同期と一時書き込み

`TrackSync` は存在する全トラックを、その時点で最も進んでいるタイムポインタへ揃えます。
`Sub{...}` は本体を通常どおりイベント化したあと、現在トラックのタイムポインタを開始位置へ戻します。

```mml
Sub{'ceg'1} cdef
```

`Sub` 内のイベントは消えません。伴奏を重ね書きしたり、同じ開始点から複数フレーズを書くための構文です。

## 同時刻イベントの順序

同一トラック・同一時刻のイベントは、ソースから追加された順序を保ちます。
したがって音色や CC は、それを適用したいノートより前に記述してください。
