# 変数・式・制御構文

## 値の種類

現行 Rust は整数、文字列、配列を扱います。

```mml
Int tempo=120
Str phrase={"cdef"}
Array chord=(60,64,67)
Array names=({mml},{panda},{dragon})
```

変数は大域です。宣言済み変数名をコマンド位置で再び書くと代入になります。

```mml
Int i=0
i=(i+1)
```

文字列変数をコマンド位置に単独で書くと、その中身を MML として再解釈します。

```mml
Str Intro={"o5 cde"}
Intro
```

## 式

式をコマンド引数に使う場合は括弧で囲みます。

優先順位は高い順に、おおむね次のとおりです。

1. リテラル、変数、配列参照、関数呼び出し、括弧
2. 単項 `+`、`-`、論理否定
3. `*`、`/`、`%`
4. `+`、`-`
5. 比較 `==`, `!=`, `<`, `<=`, `>`, `>=`
6. 論理 AND `&&`
7. 論理 OR `||`

整数 0、空文字列、空配列は偽、それ以外は真です。文字列を含む `+` は連結として使えます。
0 除算、整数オーバーフロー、未定義変数、配列の範囲外はエラーです。

## 条件分岐

```mml
Int i=0
If(i < 4) {
  c
} Else {
  r
}
```

条件は括弧で囲み、本体は `{}` で囲みます。入れ子にできます。

## While と For

```mml
Int i=0
While(i < 4) {
  c
  i=(i+1)
}

Int j=0
For(j=0; j<4; j=(j+1)) {
  d
}
```

`Exit` は現在実行中の反復から抜けるために使います。暴走防止のため、1 つの反復構文は最大 100,000 回です。
上限に達するとエラーになり、WASM のブラウザタブを固めません。

## MML 反復

`[n body]` は body を n 回演奏します。`:` がある場合、最終回だけ `:` より後を省略します。

```mml
[4 cdef]
[2 cde:f]
```

反復は入れ子にできます。ブロックや再帰を含む実行のネスト上限は 128 です。

## 関数

```mml
Function Arp(Int root, Int count=3) {
  n(root) n(root+4) n(root+7)
  Result=count
}

Int result=Arp(60)
```

引数には既定値を指定できます。`Result=value` は式の中で呼んだ関数の戻り値です。
戻り値のない関数を値として使うとエラーになります。

`Str`仮引数が1個の関数では、従来形式として括弧内のMMLを引用符なしで渡せます。

```mml
Function Echo(Str S) { S }
Echo(ドレミファソ)
```

この場合、括弧内をMML文字列として仮引数へ渡します。複数引数の関数でMMLにカンマを含める
場合は、`MidiDelay({c4,80,100},2,!8)`のように波括弧で囲んで引数境界を明示します。

文字列変数の`.s(検索,置換)`は一致する部分をすべて置換します。`fadeio.h`など、文字列として
組み立てたMMLのプレースホルダーを実際の音長へ置き換える従来Includeで使われます。

数値の関数引数にも`!1^1`のような結合音長を指定できます。`!n`はn分音符のtick数へ変換され、
`^`で続く音長を加算してから仮引数へ渡します。

`MML(name)`は現在の命令値を返します。`l/v/o/q/t/@/BR/p%/Key/TimeKey/TimeKey2/Port`に加え、
`MML(y11)`や`MML(Expression)`のようなコントロールチェンジは、そのトラックで最後に設定した
値を返します。未設定時の主な既定値は`BR=2`、`p%=-1`、`Port=0`です。

`PrintTime([track])`はトラック番号、`Time(小節:拍:tick)`、絶対tickを1行で返します。
`PrintTrack([track])`はこれに加えてチャンネル、音色、音長、ゲート、ベロシティ、タイミング、
オクターブ、ベンド、ミュート、イベント数を`CompileOutput.messages`へ格納します。トラックを
省略すると現在のトラックが対象です。存在しない番号や負の番号はエラーになります。

関数本体から大域変数を読み書きできます。ただし仮引数と同名の大域変数は呼び出し中だけ隠され、終了後に復元されます。
利用者定義関数は組み込みコマンド・関数より優先されます。たとえば `Function f(){...}` の後の `f` は音名ではなく関数呼び出しです。

## 組み込み値と関数

| 名前 | 仕様 |
|---|---|
| `on`, `off` | 1、0 |
| `SoundType` | 初期値は0（GM）。1（GS）、2（XG）などを代入・参照して音源別に分岐可能 |
| `Random(n)` | 0〜n の整数 |
| `Random(a,b)` | a〜b の整数 |
| `RandomSelect(a,b,...)` | 引数から 1 個選ぶ |
| `Step(n)` | n tick。`!n` と同じ考え方 |
| `StrToLen(n)` | 分母 n の音長を tick に変換 |
| `SizeOf(v)` | 配列要素数、文字数、整数なら4 |
| `StrToNum(s)` | 10進文字列または`$`16進文字列を整数へ変換。変換不能なら0 |
| `HEX(n)` | `$`付き・最低2桁の大文字16進文字列。配列も変換可能 |
| `#STR(v)` | 文字列化 |
| `ASC(s)` | 先頭 Unicode 文字のコードポイント |
| `CHR(n)` | Unicode コードポイントから文字列化 |
| `MID(s,index,len)` | 1起点の文字位置から文字列を切り出す |
| `POS(sub,s)` | 部分文字列の1起点位置。見つからなければ0 |
| `POSX(sub,s,start)` | 指定した1起点位置以降を検索 |
| `Replace(s,from,to,onoff)` | `off`なら最初、`on`ならすべて置換 |
| `VarType(v)` | `Int`、`Str`、`Array`のいずれかを返す |
| `ArraySortNum(a)` | 数値昇順に並べた新しい配列を返す |
| `ArraySortStr(a)` | 文字列昇順に並べた新しい配列を返す |
| `VERSION()` | 互換用バージョン数 |
| `Time(m:b:s)` | 小節・拍・stepを絶対tickへ変換 |

配列は整数と文字列の要素を保持でき、`a(index)` の添字は0起点です。`a(index)=value` で要素を
上書きできます。現在の長さ以上の非負添字へ代入すると、中間要素を整数 `0` で補いながら配列を
拡張します。`ArraySort*` は元の配列を直接変更せず、並べ替えた配列を返すため、必要なら
`a=ArraySortNum(a)` のように代入します。

乱数列は再現可能です。`System.RandomSeed=n` でシードを指定します。

## Print

`Print(value)` はコンパイラコアから標準出力へ直接書きません。成功結果の `messages` に文字列を追加し、
CLI や WASM の呼び出し側が表示方法を決めます。
