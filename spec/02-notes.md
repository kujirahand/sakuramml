# 音符・休符・音長

## 音名とノート番号

`c d e f g a b` はそれぞれド、レ、ミ、ファ、ソ、ラ、シです。
現行 Rust の既定オクターブ `o5` では `c` が MIDI ノート番号 60 になります。

```mml
o5 c d e f g a b > c
n60 n64 n67
```

`n(number)` または `nnumber` は MIDI ノート番号を直接指定します。許容範囲は 0〜127 です。
`Key`/`KeyShift` による移調は `n` にも適用されます。

## 臨時記号と調号

音名の直後の `+` または `#` は半音上げ、`-` は半音下げです。複数個を重ねられます。
明示的な臨時記号がある音には `KeyFlag` の値を重ねません。

```mml
c+ d- f##
KeyFlag+(fc)   // F と C をシャープ
KeyFlag=(0,0,-1,0,0,0,0)
```

`KeyFlag=(...)` の並びは `c,d,e,f,g,a,b` です。設定時にはキーシグネチャ・メタイベントも出力します。

## オクターブ

| 構文 | 動作 |
|---|---|
| `o5` | 現在トラックのオクターブを設定 |
| `>` / `<` | 現在値を 1 上げる／下げる |
| `` ` `` / `"` | 次の 1 音だけ 1 上げる／下げる |
| 音符の第5引数 | その音だけオクターブを上書き |

一時オクターブは次に実際に書かれる音で消費されます。

## 音長

分母による音長 `n` は、`timebase * 4 / n` tick です。既定タイムベース 96 では、
`1=384`、`2=192`、`4=96`、`8=48`、`16=24` tick です。

| 構文 | 意味 |
|---|---|
| `l8` | 後続音符の既定長を八分音符にする |
| `c4` | C を四分音符で鳴らす |
| `c4.` | 付点四分音符 |
| `c4..` | 複付点四分音符 |
| `c%48` | 48 tick を直接指定 |
| `c4^8` | 四分音符と八分音符の長さを加算 |

付点は直前までの増分の半分を順に加えます。整数除算で端数が出る場合は tick 単位で切り捨てます。
タイムベースは正数でなければなりません。SMF で表現できない時刻に達する音長はエラーになります。

## ベロシティ、ゲート、タイミング

```mml
v100 q80 t0 l4 c
c4,90,110,-2,5
c(4,90,110,-2,5)
```

音符引数の標準順は `l,q,v,t,o` です。省略位置は空のカンマで表せます。
個別引数はトラックの既定状態より優先します。

- `v`: 音の強さ。現行 Rust は `v * floor(128 / vMax)` を 0〜127 に丸めます。
- `q`: 音長に対する発音割合。`System.qMax` が 100% に相当します。
- `t`: ノートオン時刻を tick 単位で前後させます。タイムポインタ自体には影響しません。
- ノートオフ時刻は `発音開始 + max(音長 * q / qMax - 1, 1)` です。
- 次の音の基準時刻は、ゲートではなく音長ぶん進みます。

## 休符とタイ

`r` はイベントを作らず、指定音長だけタイムポインタを進めます。
`^` は直前の音のノートオフを延長します。延長後のゲートは、最初の発音開始から累積音長に対して再計算します。
直前に延長できる音がない `^` は休符と同様に時刻だけを進めます。

## 和音

単引用符で囲んだ音は同じ時刻から発音します。閉じ引用符の後の音長が和音全体の長さです。

```mml
'ceg'4 'dfa'2
```

内部の各音は同一の開始時刻を持ち、和音を閉じた時点でタイムポインタが一度だけ進みます。

## 連符

`Div{body}length` は、本体に含まれる音数で全体長を等分します。

```mml
Div{cde}4   // 四分音符の長さに3音を収める
```

本体終了後のタイムポインタは常に `length` 後です。分割の結果は最低 1 tick です。

## `.onNote`

`v`、`q`、`t`、`l`、`o` には、音ごとに値を巡回させる `.onNote`（短縮形 `.N`）を指定できます。

```mml
v.onNote(120,80,100) cdefg
l.onNote(4,8) cdef
```

列の末尾まで使うと先頭へ戻ります。音符に直接書いた個別引数は `.onNote` より優先します。
その他の先行指定については [互換性表](10-compatibility.md) を参照してください。
